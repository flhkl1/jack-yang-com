Problem

The Clinical Dementia Rating (CDR) is the gold standard interview for staging dementia, and it is too slow for primary care. Our lab, the UCSF NeuroAI Lab, built the vCDR, an agent that administers it over the phone. There was no way to evaluate the agent.

Solution

vCDR-bench runs the agent against a simulated participant and scores the interview.

Metric design and methodology

Definitions

A configuration is a speech to text model s, a language model l, and a text-to-speech (voice) model v.

x = (s, l, v) ∈ X = S × L × V

This represents an interviewer built with a cascaded architecture, which we chose because the speech-native alternatives were cost-prohibitive.

An item is a fixed interview task. It includes an interviewer script q, a participant script p, and a list A of checkpoints in the interview that we want to reach. A checkpoint is one scripted question that the interviewer has to ask and get an answer to.

i = (q, p, A) ∈ I

A = (a1, …, am)

A run is a simulated interview (configuration x item), which we run n times.

R(x, i; n) = { rk(x, i) : k = 1, …, n }

Two subsets matter, with the same signature:

C(x, i; n) ⊆ T(x, i; n) ⊆ R(x, i; n)

T is the tracked runs, those whose outcome was recorded. C is the completed runs, those that reached every checkpoint, carried each one through to its last scripted response, and never stalled. Below, R, T and C are short for these three sets at a fixed x, i and n.

A metric scores a run from 0 to 1, where 1 is always best:

μ : Runs → [0, 1]

The aggregate score takes a configuration and an item and is computed from R(x, i; n):

Score : X × I → [0, 1]

1. The aggregate score

Each configuration x gets one score on item i, computed over all of its runs R:

Score(x, i) = (0.35 × Protocol + 0.30 × Quality + 0.20 × Completion + 0.15 × Efficiency) ÷ (sum of the weights of the terms that have a value)

Each term is between 0 and 1. If a term could not be measured, it is left out and the remaining weights are rescaled, so a missing test never counts as a zero or as a pass.

2. The four terms

Raw measurements where lower is better, such as how often an answer was disclosed, are flipped so that 1 is best.

Protocol = mean, over r ∈ C, of the mean of μ(r) over the protocol metrics

Quality = mean, over r ∈ C, of the mean of μ(r) over the quality metrics

Completion = |C| ÷ |T|

Stalled, incomplete and contaminated runs are in T but not in C, so they count as failures.

Efficiency = 0.6 × Turns + 0.4 × Latency

Turns = (60 − τ) ÷ (60 − 16), limited to 0..1, where τ is the Kaplan-Meier median number of turns to completion

Latency = (15,000 − λ) ÷ (15,000 − 3,000), limited to 0..1, where λ is the median across runs of each run's 95th-percentile turn latency in ms

Turns scores 0 when most runs never complete, because the median is then undefined. A run that stalls counts as needing more turns than were observed, not as missing.

3. Pass rates, reported next to the score

An average can hide a total failure on one metric. So each run is also marked pass or fail on two dimensions, administration fidelity and interaction experience, and it passes a dimension only if every metric in it meets its threshold. With n runs of which j passed, k = 5, and binom(a, b) the number of ways to choose b from a:

pass@1 = j ÷ n

pass@k = 1 − binom(n − j, k) ÷ binom(n, k)

pass^k = binom(j, k) ÷ binom(n, k)

pass@k is the chance that at least one of k interviews passes. pass^k is the chance that all k do.

4. Uncertainty

Every figure carries a 95% interval from 10,000 bootstrap resamples of the runs, with the whole statistic recomputed on each resample.

5. What goes into it

The weights and thresholds are starting points. They have not yet been calibrated against clinician judgment.

The full list of metrics

Protocol adherence

  • Question order correct
  • Branching correct
  • Questions skipped
  • Attempt limit exceeded
  • Probed after a correct answer
  • Denied a second attempt
  • Answer disclosed to the participant

Elicitation quality

  • "I don't know" accepted on fact-based questions
  • Probed further on subjective questions
  • Recent-event (ARQ) questions covered
  • Recent-event (ARQ) questions re-asked redundantly
  • Scripted anchor coverage

Completion

  • Completion status (completed, incomplete, stalled, contaminated, not tracked)
  • Anchors reached out of total
  • Last anchor reached
  • What ended the run (interviewer, stall detector, turn limit)
  • Completion rate

Efficiency

  • Turns to completion (Kaplan-Meier median)
  • Interviewer turns per run

Latency

  • End-to-end turn latency (p50, p95, mean, min, max)
  • Time to first audio
  • Speech-to-text latency
  • LLM latency
  • Text-to-speech latency
  • Per-chunk audio arrival times

Failure modes

  • Stalled, no progress
  • Stalled, repeating itself
  • Anchor skipped
  • Ended early
  • Turn budget exhausted
  • Question never asked
  • Fixture off script
  • Runtime failure
  • Aborted
  • Runtime signals, including empty or silent turns

Robustness under perturbation

  • Background noise (signal-to-noise ladder)
  • Packet loss
  • Codec degradation
  • Faster speech
  • Slower speech
  • Disfluency at utterance edges
  • Disfluency inside utterances
  • Off-script confused answers
  • Telephony composite
  • Degradation slope per perturbation strength
  • Area under the degradation curve
  • Score retention
  • Paired permutation significance, Holm-Bonferroni corrected

Aggregate scores

  • Weighted composite (protocol, quality, completion, efficiency)
  • Administration fidelity dimension (vCDR-A)
  • Interaction experience dimension (vCDR-X)
  • pass@1, pass@k, pass^k
  • Pareto frontier over the two dimensions
  • Bootstrapped 95% confidence intervals
  • Variance decomposition

Validation

  • Human agreement (ICC, kappa), wired but unavailable without clinician scores
